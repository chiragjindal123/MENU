Menu Detection - Live Camera Application

REQUIREMENTS:
- Python 3.8 or higher
- Windows 10/11
- Webcam

FIRST TIME SETUP:
1. Double-click "setup.bat"
2. Wait for installation to complete

TO RUN:
- Double-click "run.bat"

CONTROLS:
- Press 'Q' to quit
- Press 'S' to save screenshot
- Press '1-6' to change detection speed
